# 02 — Nombre y marca

## Decisión final: **Kamay**

| Dato | Valor |
| --- | --- |
| Nombre | **Kamay** |
| Repositorio | `kamay` → `github.com/joseamaya/kamay` |
| Origen | **Quechua** |
| Significado | *Crear, formar, fundar*; en su uso andino también *animar / dar ánima* |
| Pronunciación | **ka-MAY** (palabra llana) |
| Eslogan | *«Kamay — moldea clases, da vida a objetos»* |

### Por qué Kamay

- **Cubre las dos acciones centrales** del entorno: el estudiante **crea/formas**
  una clase y **da vida** a los objetos que instancia a partir de ella.
- El vínculo con *animar / dar ánima* es documentado: `Pacha Kamaq` se traduce
  como "el que anima/crea el mundo"; en crónicas coloniales, `kamay` es
  *animar* y deriva de `kama`, *ánima* (ver Wikipedia, *Pacha Kamaq*; y
  Wiktionary, *kamay* = crear, formar, fundar; agentivo `kamaq`).
- **Corto, sonoro y fácil** de pronunciar para hispanohablantes.
- Disponible como repositorio de GitHub en la cuenta del autor (verificado).

### Nota de respeto cultural

Al ser un nombre de origen andino, el `README` y un `CREDITS` deben incluir su
**origen, significado y pronunciación**, y un agradecimiento a la lengua
quechua. El nombre es identidad, no adorno.

## Criterios usados para elegir

1. **Fácil de pronunciar** para el público objetivo.
2. **Evocador de la metáfora central de la POO**: la **clase** es un molde y el
   **objeto** es lo que nace de él.
3. **Corto** y cómodo como nombre de repositorio y de dominio.
4. **Lúdico**, no académico ni frío.
5. **Con identidad propia**, distinta del legado "Elix".
